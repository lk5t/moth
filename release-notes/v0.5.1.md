## MOTH v0.5.1 — Every file comes over

**Already on v0.5.0?** MOTH offers this update by itself (Settings → Updates → Check now). It's signed and installs in a few seconds. **On v0.4.0 or older?** Download `MOTH_0.5.1_x64-setup.exe` below and run it once.

### What's new
- **Every file type is imported.** v0.5.0 only copied files it could show (images, PDFs, audio, video, text…) and skipped the rest. Now every file in your vault comes over: 3D models (glb, gltf, fbx, obj, mtl, stl, dae), textures (hdr), scripts, web shortcuts, anything. MOTH still only shows a preview for images, PDFs, audio, video and text; other files are kept safely and listed under Library → Files.
- **Importing the same vault again only adds what's missing.**
  - Notes already in MOTH are skipped, as before.
  - Files that were already copied are recognised and reused. They aren't read or copied again, so a second import of a big vault is quick.
  - New files go into the same folder as the first import, so there's no second copy of the vault.
  - The preview shows how many files are already in MOTH. The disk space check only counts what's new.
- **Links catch up.** If a note from an earlier import links to a file that only arrives now (for example `![[ship.glb]]`), the link is connected automatically.
- **Undo stays careful.** Undoing the second import removes only the files it added that no note uses. Nothing from the first import is touched.

### What was tested
- **Engine:** 113 automated tests, all passing. They include a new one that imports a vault without its 3D files and then imports it again with them. It checks that:
  - only the missing files were copied, into the same folder;
  - the earlier note's link to the model now connects;
  - undo removed only the new, unused file;
  - the vault itself was byte-for-byte unchanged.
- **Windows:** the installer is built, installed and started on a clean Windows machine by the build system.
- **Updates:** the update file is signed and its signature is checked, including that a changed copy is refused.
