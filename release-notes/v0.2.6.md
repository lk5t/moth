## MOTH v0.2.6 — Awakening

**Download:** `MOTH_0.2.6_x64-setup.exe` below. Run it; it updates your existing MOTH and keeps all your memories.

### What's new
- **The Mind looks alive.** Small, soft glowing nodes. Hover a memory and it lights up with its connections while the rest fades; click to glide the camera to it.
- **Projects form their own clusters** instead of one big blob — tested up to 2,000 memories.
- **Real-time learning animations.** New memories fade in near related ones, new connections draw themselves in, and a small "N memories learned" note appears. Only real changes trigger them — never fake activity.
- **Startup animation.** A short moth "wake up" that never slows MOTH down.
- **Cortex activity moth.** A small flapping moth shows only while Cortex is really working.
- **Smoother app.** Sliding sidebar marker, page fades, button feedback.
- **New setting:** Settings → General → Motion (Automatic / Full / Balanced / Minimal). Automatic follows Windows' "reduce animations".

### Fixes from the real-PC checkup
- Settings no longer jumps back to the first section.
- Warns you if the Quick Capture shortcut is already used by another app (default is now Ctrl+Shift+Space).
- Shows the real shortcut, counts older backups correctly, and lets MOTH choose a preference's area.

### Tested
Engine tests, real local-AI test on Windows and Linux, and install + tray + clean-quit checks on a fresh Windows machine all passed.
