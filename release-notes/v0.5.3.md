## MOTH v0.5.3 — Faster with big vaults

**On v0.5.0 or newer?** Settings → Updates → Check for updates. **On v0.4.0 or older?** Download `MOTH_0.5.3_x64-setup.exe` below and run it once.

### What's faster
- **Importing many files is about 40× faster.**
  - **The problem:** after every single file, MOTH recounted the whole import to update the progress bar. For a vault with tens of thousands of small files (textures, model parts…) that made it crawl at about 20 files a second.
  - **The fix:** MOTH now keeps the count as it goes and updates the progress bar a few times a second. Small files are also copied in one step.
  - **Measured:** a vault like a large Roblox-dev vault (848 notes plus 38,000 files in 2,500 folders) now imports in **44 seconds instead of about 31 minutes**.
- **The Library stays smooth during an import.** It used to reload the whole folder tree, file list and counts every time the progress bar moved. Now it refreshes when notes arrive and when the import finishes.
- **The Files list is instant with tens of thousands of files.** Each page used to sort every file (up to 0.25 s); it now loads in about 3 ms.
- **The Mind and the Overview** load big vaults in a fraction of a second (from v0.5.2).

### Notes
- The database gets one small addition: an index, so the Files list doesn't have to sort. MOTH saves a backup copy of the database first, as with every upgrade. Nothing is changed or removed.
- Imports already in progress keep going after the update and benefit straight away.

### What was tested
- **Engine:** 115 automated tests, all passing. They include pausing an import, a crash in the middle of one, resuming, and an update during an import.
- **Large vault:** the benchmark above, using the real import code on a test computer: all 848 notes and 38,000 files imported, 10,360 links connected, no errors. The longest moment MOTH was busy during the import was 0.5 s.
