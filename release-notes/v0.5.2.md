## MOTH v0.5.2 — The Mind, untangled

**On v0.5.0 or v0.5.1?** MOTH offers this update by itself (Settings → Updates → Check for updates). **On v0.4.0 or older?** Download `MOTH_0.5.2_x64-setup.exe` below and run it once.

Big vaults turned The Mind into one dense grey ball. This update fixes the cause, not just the look.

### What was wrong
- **No grouping for notes.** Imported notes had no group, so they were all pulled to the same centre.
- **Index notes pulled everything in.** Notes that link to hundreds of others (like `VAULT_INDEX`) dragged each of those notes towards themselves.
- **Slow to load.** Counting each note's links was slow: about 3 seconds for an 848-note vault, and minutes for 3,000 notes. During that time MOTH was busy.

### What's new
- **Regions you can read.** Notes are grouped by the top folder they live in (for example "02 Luau Scripting") and memories by their project. Each group forms its own region with its name. Regions that link to each other a lot sit side by side.
- **Neurons instead of squares.**
  - Soft glowing circles: lavender for memories, cool blue for notes.
  - Size comes from real connections and importance.
  - Index notes and core memories glow a little more.
  - Connections are thin, gently curved pathways.
- **Less clutter, more detail as you zoom.**
  - **Zoomed out:** connections between regions are drawn as one soft bundle per pair of regions, so you see the overall shape.
  - **Zooming in:** individual connections fade in.
  - **Names never overlap:** region names show when zoomed out, and note and memory names as you get closer.
  - **Hover:** shows a neuron's own connections and dims the rest.
- **Subtly alive.**
  - **Activity pulses:** now and then a soft pulse travels along a connection of something that changed recently. If nothing changed, nothing pulses.
  - **Hover:** a short wave runs along the hovered neuron's connections.
  - **Selection:** selecting a neuron sends out one ripple.
  - **Reduced motion:** all of this is off with Motion set to Minimal or when Windows asks for reduced motion.
- **Faster.** The Mind and the Overview load big vaults in a fraction of a second: 0.13 s instead of 3.4 s for 848 notes, and 0.5 s instead of 2½ minutes for 3,000.
- **Your layout is safe.** The first time you open The Mind after updating, the graph is laid out once with the new method, then saved. After that it stays where it is. Nothing in your memories, notes or links is changed or hidden.

### What was tested
- **Engine:** 115 automated tests, all passing. New: notes are grouped by their real folders, and a 1,500-note vault's graph loads in under 1.5 s with correct link counts.
- **The Mind in a real browser:**
  - **Vaults tested:** 18 memories; 120 notes with 42 memories; a vault shaped like a large Obsidian vault (848 notes in 56 folders, about 10,400 connections, index notes); and 3,000 notes with 302 memories (51,000 connections).
  - **Checked:** no overlapping neurons; hover, selection, search highlight, filters, zoom and fit; the Overview mini graph; positions stay put after a reload; no pulses with reduced motion; no errors.
- **Smoothness:** measured on a slow cloud machine with no graphics card, using the app's own "Check smoothness": 16–33 fps for the 848-note vault (about the same as before) and 13–22 fps for 3,000 notes (before, that size didn't load). A normal PC is faster.
