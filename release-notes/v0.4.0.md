## MOTH v0.4.0 — Consciousness

**Download:** `MOTH_0.4.0_x64-setup.exe` below. Run it; it updates MOTH and keeps all your memories (the database is upgraded automatically and nothing is removed).

MOTH now does more with what it already knows: it keeps track of where each project stands, notices what needs attention, finds useful connections, checks the health of your knowledge and runs four small helpers in the background. Everything it shows comes from things you or Claude saved, and every result says where it came from. It doesn't watch your conversations, and it isn't sentient.

### Pick up where you left off
- **Project state:** each project now has objectives, unresolved decisions, blockers and milestones, next to its decisions, tasks, research and lessons. Progress is shown only when milestones or tasks give a real number; otherwise it says "unknown".
- **Resume a project:** one click (or Claude calling `moth_resume_project`) gives what was completed last, the decisions, what's still open, research that may help (with the reason), and a suggested next step taken from what's recorded.
- **Session handoffs:** at the end of a session Claude can save a handoff (summary, completed work, decisions, unresolved issues, next steps). Saving the same session again updates it instead of making a copy, and earlier versions are kept. You can write or edit handoffs in Projects too.
- **Claude Code:** if you turn on Settings → "Write a handoff when a Claude Code session ends", MOTH writes one with its local AI when a Claude Code session ends. Claude Desktop has no such hook, so there it happens when Claude calls the tool or when you write one.

### Noticing and checking
- **Needs attention:** open decisions, blockers, unfinished work, knowledge gaps, research to review, lessons that may help, and requirements that may conflict.
- **Knowledge Health:** 11 checks (duplicates, possible duplicates, conflicts, missing sources, claims without support, broken connections, old research, quiet projects, mixed-up preferences, the search index and similarity data). Only rebuildable things are repaired automatically (and logged); everything else is a suggestion you approve.
- **Discoveries (quiet):** a lesson that fits another project, research that may answer an open question, notes that back up a decision. Only confident ones, no pop-ups, and nothing is connected until you press Connect.

### Agents
- **Research Analyst, Memory Curator, Project Analyst, Knowledge Connector** run on MOTH's job system and local AI, one job at a time. You can turn each on or off, choose how often it runs in the background and how much it does per run. Merging, moving, creating or deleting knowledge always waits for your approval. They never run programs, browse the web or read your files.

### The Mind 3.0
- **Path:** pick two memories and see the chain of saved connections between them, step by step with the reasons. If there's none, it says so.
- **History:** slide back through the days your knowledge changed and see the graph as it was, with titles as they were then.
- **Suggestions** (dashed lines) and **attention** rings can be shown on the graph when you want them.

### MOTH Connect
- **Permissions per app and per project:** for example, let Claude Desktop read everything but keep Claude Code out of a private project. It's enforced on every tool call: answers leave those memories out and say how many were left out, and changes there are refused.
- **Honest connection status** for each app (connected, disconnected, error, authorization required, configured, restart required) with the evidence behind it.
- **Deeper diagnostics:** server start, tool list, a tool call, memory retrieval, handoff retrieval and error handling, all run for real.

### MOTH Pulse 2.0
- The Overview leads with active projects, unresolved decisions, pending reviews and strong discoveries, then shows where to pick up each project, what needs attention, discoveries, agent activity and knowledge health.

### Performance (measured)
Measured with `core/scripts/bench.ts` on generated notes (a cloud test machine: 2-core Intel Xeon 2.8 GHz, Linux, Node 22). Your computer will differ. The same benchmark on a Windows build machine (2-core AMD EPYC, Windows 11 build 26100) at 1,000 memories: search 7.5 / 13.5 ms, graph 20 ms, Overview 41 ms, health check 0.9 s (0.1 s after 20 edits), discovery 1.4 s, longest pause 38 ms; saving an edit was usually under 1 ms but occasionally up to 175 ms there (disk writes are slower on Windows).

### Good to know
- MOTH's similarity is word-based (it runs on your computer without a big model), so ideas phrased very differently can be missed.
- The local AI is needed only for the written parts (agent insights, automatic handoffs, briefings). Everything else works without it.
- No cloud processing unless you've explicitly allowed it, as before.
